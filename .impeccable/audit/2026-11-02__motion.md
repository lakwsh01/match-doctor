# Motion audit: Match Doctor web (2026-11-02)

Scope: `web/src` (sign-in, current report) and `web/src/v2` (trial report). Mode: Operate/Read. Motion serves feedback, state, and continuity; no page-load choreography.

## Inventory

| Where | What moves | Duration / easing | Trigger frequency |
| --- | --- | --- | --- |
| `styles/global.css` | Reduced motion: every animation and transition forced to 0.01ms | — | always |
| `styles/tokens.css` | One token: `--ease-out: cubic-bezier(0.16, 1, 0.3, 1)` | — | — |
| Sign-in submit (`AuthStep`) | Hover opacity 1 → 0.88 | 150ms `ease` (default) | few per session |
| Code field (`CodeField`) | Caret blink, border colour | 1s steps, 150ms `ease` | sign-in only |
| Text field (`TextField`) | Border colour | 150ms `ease` | sign-in only |
| Select (`Select`) | Chevron rotate; popover enter keyframe translateY(-4px)+fade; no exit; origin centre | 150ms `--ease-out` | few per session |
| Segmented control | Hover background, selected fill — instant | — | tens per session |
| Report body (v1 + v2) | Dim to 0.55 while a report loads | 150ms `ease`, no delay | per report switch |
| Rally strip (v1) | Non-selected bars dim | 200ms `--ease-out` | per rally pick |
| Court trace mode (`Court` `trace`) | Ball path draws, marks fade in on a 1.2s stagger | 1.2s `--ease-out` path, 250ms marks | never today: `CourtView` passes `trace={false}` |
| v2 tabs | Indicator and content swap instantly; scroll jumps to the bar | — | tens per session |
| v2 rail | Ball slides to the phase; click scrolls smoothly; scroll-spy also moves the ball | 600ms `--ease-out` | per phase / while scrolling |
| v2 video dock | Appears and disappears instantly; on wide screens the report column narrows instantly | — | per watched rally |
| v2 hovers | Colour/ring swaps, instant | — | constant |
| Page to page | Sign-in → report, sign out, v1 ↔ v2 link: hard cuts (full reload for v1 ↔ v2) | — | rare |

## Audit 1: inline motion

| Before | After | Why |
| --- | --- | --- |
| No `:active` state on any control | `transform: scale(0.97)` on `:active`, 120ms `--ease-out`, on button-shaped controls (segmented option, select trigger, sign-in submit, dock close, Diagnosis plan action, rail chips, evidence chips) | Press must feel heard; text tabs and underlined text links keep no scale |
| Hover swaps not gated; tap on a phone leaves a stuck hover fill (segmented option, select trigger, Diagnosis action ring) | Wrap every `:hover` rule in `@media (hover: hover) and (pointer: fine)` | Touch fires hover on tap |
| Hover colour swaps are instant in v2, 150ms `ease` in v1 | One rule: `transition: color, background-color, box-shadow, border-color` at `--dur-hover` (150ms) `ease` | Same hover feel on every screen; colour changes use `ease`, not a deceleration curve |
| Sign-in submit hover fades to 0.88 opacity | Hover adds the night ring used by v2 actions (`box-shadow: inset 0 0 0 2px var(--ink)`) | A fading primary button reads as disabled (disabled is 0.55) |
| Select enter: keyframe from `translateY(-4px)`, origin centre, no exit | Enter from `scale(0.96)` + opacity 0, `transform-origin: var(--radix-popover-content-transform-origin)`, 160ms `--ease-out`; exit keyframe 100ms opacity only | Popovers grow from their trigger; exit faster than enter |
| Select chevron 150ms `--ease-out` | Keep, on `--dur-hover` token | Fine, just tokenised |
| v2 tab switch: content swaps with no transition | New panel fades in, opacity only, `--dur-view` (180ms) `--ease-out`; skipped when the switch came from the keyboard; no indicator slide | Hides the hard swap without delaying it; keyboard moves are repeated and must be instant |
| Report switch dim starts immediately | Dim waits 120ms before starting; undim is immediate | A cached report would otherwise flash grey for one frame |
| Rail ball 600ms `--ease-out` | 420ms `--ease-in-out` (`cubic-bezier(0.77, 0, 0.175, 1)`) | On-screen movement accelerates and settles; 600ms trails the scroll |
| Rail click: smooth scroll lets scroll-spy move the ball through every phase it passes | Ignore scroll-spy until `scrollend` (or 700ms fallback) after a click | The ball should go straight to the picked phase, not zigzag |
| v1 court path draws with `--ease-out` while marks appear at even intervals | Path draws `linear` over the same 1.2s | The line should reach each contact as its mark appears |
| List items entering (takeaways, watch list, rally index, streaks, filters) appear at once | Keep instant; no stagger | Data lists are read repeatedly; stagger would delay reading |
| Court marks stagger (`trace` mode) | Keep, on tokens | Explanatory replay if a screen turns it on again |
| Code field caret blink | Keep; already stops under reduced motion | Correct |

## Audit 2: page and screen level

| Before | After | Why |
| --- | --- | --- |
| Durations hard-coded (0.15s, 0.2s, 0.25s, 0.6s, 1.2s) and easing mixes `ease`, default, and one curve | Motion tokens in `styles/tokens.css`: `--dur-press 120ms`, `--dur-hover 150ms`, `--dur-pop 160ms`, `--dur-view 180ms`, `--dur-sheet 280ms`, `--dur-focal 420ms`, `--dur-trace 1.2s`; `--ease-out` (existing), `--ease-in-out`, `--ease-drawer` | One vocabulary across sign-in, v1, and v2 |
| Reduced motion: global 0.01ms hammer in v1, `transition: none` in v2 | Tokens carry it: under `prefers-reduced-motion` the movement durations (`--dur-press`, `--dur-sheet`, `--dur-focal`, `--dur-trace`) go to 0ms; fades and colour (`--dur-hover`, `--dur-pop`, `--dur-view`) stay; keyframes with movement switch to fade-only; drop the hammer | Reduced means fewer and gentler, not none; state fades still explain what changed |
| Video dock appears instantly; on wide screens the report column snaps narrower | Wide: dock fades and slides in 12px from the right, `--dur-sheet` `--ease-out`; column change stays instant (no grid animation). Phone: sheet rises from `translateY(100%)`, `--dur-sheet` `--ease-drawer`. Exit: instant | Occasional overlay, standard entrance; animating the grid would reflow the whole report every frame |
| Tab change scroll: instant jump; rail click: smooth scroll | Rule: new view = instant scroll to the bar + panel fade; same page = smooth scroll (reduced motion: instant) | Navigation type decides the motion, the same on every screen |
| Report switch: panel remounts with no entrance | Same panel fade as a tab change | Game 1/2/3/Match switches are views too |
| Players subject switch (v2): instant | Same panel fade, scoped to the subject area | Consistent with tabs |
| Sign-in → report, sign out, v1 ↔ v2: hard cut | App shell fades in once on mount, `--dur-view` opacity only | Rare, one-off moment; no cross-document view transition (the SPA paints an empty root first, so it would fade to blank) |
| Two loading dims written twice (v1 `Reports`, v2 `ReportsV2`) | Same tokens and delay in both | Consistency |

## Do not animate

- Keyboard tab moves, arrow-key segment moves, Escape closing the dock.
- Filters and sort in the rally index; list rows; dumbbells and bars on data change.
- The segmented selection fill (it changes with the content beside it).
- Anything on scroll other than the rail ball.
